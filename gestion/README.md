## Principio de organizacion

El proyecto se gestiona mediante celulas verticales y equipos horizontales. Las celulas desarrollan modulos; los equipos horizontales definen lineamientos comunes para arquitectura, datos, UX/UI, testing, DevOps, documentacion e IA.

Todo estudiante debe asumir responsabilidades dentro de su celula, participar en las decisiones transversales y demostrar comprension del producto completo.

## Herramientas

- GitHub: codigo, Issues, Pull Requests, documentos y seguimiento tecnico.
- GitHub Project: tablero general de trabajo.
- Teams: reuniones, discusiones y evidencias audiovisuales.
- Moodle: entregas formales y calificacion.
